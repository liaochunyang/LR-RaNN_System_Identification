# Lipschitz Regularized Randomized Neural Networks for System Identification
Numerical experiments for paper LR-RaNN: Lipschitz Regularized Randomized Neural Networks for System Identification.

**Paper:** LR-RaNN: Lipschitz Regularized Randomized Neural Networks for System Identification. 
Proceedings of the 1st Conference on Topology, Algebra, and Geometry in Data Science(TAG-DS 2025). <a href="https://proceedings.mlr.press/v321/liao26a.html" target="_blank">(doi)</a>

This repository contains comparison with Lipschitz Neural Network (LNN) and Neural Network with Lipschitz regualrization term (LRNN). We used some examples or models from those two papers, see <a href="https://github.com/shiqingw/Lipschitz-System-ID/tree/main" target="_blank">Lipschitz Neural Network</a> and <a href="https://github.com/enegrini/System-identification-through-Lipschitz-regularized-neural-networks" target="_blank">Lipshitz Regularization</a> for more details.
